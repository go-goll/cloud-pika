# Cloud Pika Atlas Ops UI 设计执行规范

本文档用于指导前端同事基于 `Atlas Ops` 方案落地 Cloud Pika 新 UI。设计目标是一个面向开发者和运维人员的高密度、多云对象存储工作台，优先保证扫描效率、批量操作效率、跨平台一致性和深浅主题质量。

参考原型路径：

- `docs/atlas-ops-ui-prototype/DesignShowcasePage.tsx`
- `docs/atlas-ops-ui-prototype/DesignShowcasePage.css`
- `frontend/src/pages/DesignShowcasePage.tsx`
- `frontend/src/pages/DesignShowcasePage.css`

## 1. 设计定位

`Atlas Ops` 是 Cloud Pika 的主界面设计方向，不再保留其他视觉方案。

核心关键词：

- 专业、稳定、克制
- 高密度信息展示
- 多云账户和 Bucket 快速切换
- 对象列表为第一优先级
- 状态、传输、治理信息常驻可见

不要做成营销页、卡片堆叠页、过度装饰页或大面积插画页。Cloud Pika 是每天反复使用的桌面工具，界面需要安静、可靠、耐看。

## 2. 窗口尺寸

产品窗口按以下尺寸设计和验证：

| 类型 | 宽度 | 高度 | 要求 |
| --- | ---: | ---: | --- |
| 默认最佳尺寸 | 1280 | 820 | 主设计画布，所有核心信息应完整展示 |
| 最小可用尺寸 | 960 | 680 | 不允许横向溢出，不允许标题栏和工具栏遮挡 |

执行规则：

- 所有核心页面必须在 `1280×820` 下完成视觉评审。
- 所有核心页面必须在 `960×680` 下完成可用性验证。
- 低于 `960×680` 可以降级布局，但不能作为主要设计依据。
- 固定侧栏布局必须显式扣除侧栏宽度，避免 Windows 最小窗口下出现横向滚动。
- 表格、工具栏、标题栏、右侧检查器必须使用 `minmax(0, 1fr)`、文本截断和稳定列宽。

## 3. 页面框架

主工作区由四层组成：

1. 自定义标题栏
2. 左侧侧边栏
3. 中央对象工作区
4. 右侧检查器

布局建议：

```text
┌────────────────────────────────────────────────────────────┐
│ 标题栏：平台窗口控件 / 命令搜索 / 全局按钮                 │
├───────────────┬──────────────────────────────┬─────────────┤
│ 侧边栏         │ 中央对象工作区                │ 右侧检查器   │
│ 账户/Bucket    │ 指标 / 工具栏 / 对象表格       │ Bucket/队列  │
└───────────────┴──────────────────────────────┴─────────────┘
```

推荐尺寸：

- 标题栏高度：macOS `48px`，Windows `52px`
- 侧边栏展开宽度：`224px`
- 主内容内边距：`16px`
- 右侧检查器宽度：`252px` 到 `320px`
- 表格行高：`42px` 到 `44px`
- 图标按钮：`32px × 32px`
- 主要操作按钮高度：`32px`
- 卡片/面板圆角：`8px`

## 4. 跨平台标题栏

必须同时支持 macOS 和 Windows。

macOS：

- 左侧显示红黄绿交通灯。
- 命令搜索入口居中偏左。
- 标题栏需要保留可拖拽区域。
- 快捷键显示 `⌘K`。

Windows：

- 左侧显示应用图标和 `Cloud Pika`。
- 右侧显示最小化、最大化、关闭按钮。
- 关闭按钮 hover 使用 Windows 习惯的红色背景。
- 命令搜索入口不得靠近右侧窗口控件。
- 快捷键显示 `Ctrl K`。

通用规则：

- 标题栏内所有按钮必须避开拖拽区域。
- 标题栏按钮最小点击区域为 `32px`。
- 标题栏文字不得依赖固定英文宽度，中文和英文都要截断。
- Windows 下尤其注意 125% 缩放，窗口按钮区域不能被工具按钮覆盖。

## 5. 主题系统

必须支持浅色和深色两套主题。不要用简单反色，必须使用语义变量。

浅色 Atlas 变量参考：

```css
--atlas-bg: #eef3f7;
--atlas-panel: #fbfcfd;
--atlas-panel-2: #e4ecf2;
--atlas-line: rgba(34, 52, 63, 0.14);
--atlas-text: #17222b;
--atlas-muted: #62717d;
--atlas-accent: #0b74e5;
--atlas-accent-2: #18a0a6;
--atlas-warn: #d27816;
--atlas-good: #0e9f6e;
```

深色 Atlas 变量参考：

```css
--atlas-bg: #0d1115;
--atlas-panel: #171c22;
--atlas-panel-2: #202832;
--atlas-line: rgba(218, 230, 236, 0.12);
--atlas-text: #edf3f7;
--atlas-muted: #96a5af;
--atlas-accent: #5aa2ff;
--atlas-accent-2: #36d0b2;
--atlas-warn: #ffbd5a;
--atlas-good: #4fd18b;
```

主题执行规则：

- 背景、面板、边框、正文、弱文本、强调色、成功色、警告色都必须使用变量。
- 深色模式中不要使用纯黑背景，避免视觉过硬。
- 浅色模式中不要使用大面积纯白，保持轻微蓝灰工作台质感。
- 状态标签在深色下需要提高背景透明度，保证可读性。
- 阴影在深色下应更克制，主要依赖边框和面板层级。

## 6. 侧边栏

侧边栏用于导航、Bucket 切换和账户状态展示。

内容顺序：

1. 品牌区：Logo、Cloud Pika、工作区副标题
2. 主导航：对象浏览、传输任务、治理策略、存储概览
3. Bucket 列表：当前账户下高频 Bucket
4. 当前账户状态：在线状态、厂商、区域

规则：

- 展开宽度推荐 `224px`。
- Bucket 名称必须单行截断。
- 当前 Bucket 使用弱背景 + 强调色，不使用大面积高饱和背景。
- 在线状态使用小圆点，不要用大徽章。
- 侧边栏不是营销区，不放说明性长文案。

## 7. 中央对象工作区

中央区域是产品核心，优先级最高。

组成：

1. 页面标题和治理健康入口
2. 四个关键指标：对象、存储、CDN、队列
3. Bucket 面包屑和工具栏
4. 对象表格

工具栏规则：

- 左侧为面包屑：账户/Bucket/路径。
- 右侧为视图、排序、刷新、上传。
- 上传是主按钮。
- 排序、刷新、视图切换使用图标按钮或图标+短文本。
- 工具栏在 `960×680` 下可以横向滚动内部按钮，但页面不能横向溢出。

表格列建议：

| 列 | 建议宽度 | 内容 |
| --- | ---: | --- |
| 名称 | 自适应，最小 230px | 图标、对象 key、二级元信息 |
| 大小 | 88px | 文件大小 |
| 更新时间 | 116px | 相对时间或短日期 |
| 状态 | 96px | Ready / Private / CDN stale |
| 操作 | 36px | 更多菜单 |

表格规则：

- 行高 `42px` 到 `44px`。
- 文件名和 meta 必须单行截断。
- 状态标签使用小胶囊，不要使用大 Badge。
- 警告状态使用 `--atlas-warn`，成功状态使用 `--atlas-good`。
- Hover 只做轻微背景变化，不做大位移。
- 选中态要能与 hover 态区分，建议使用强调色边框或淡背景。

## 8. 右侧检查器

右侧检查器用于降低弹窗数量，让常用状态常驻可见。

建议模块：

1. 当前 Bucket：版本控制、HTTPS、生命周期、公开策略
2. 传输队列：上传、下载、远程抓取进度
3. 快速动作：批量复制 URL、CDN 刷新、下载选中

规则：

- 宽度建议 `252px` 到 `320px`。
- 信息要短，避免段落化。
- 进度条高度建议 `6px`。
- 快速动作按钮高度 `32px`。
- 在最小宽度下可以保留；低于产品最小宽度才允许隐藏或折叠。

## 9. 图标和按钮

图标统一使用 `lucide-react`。

按钮规则：

- 图标按钮尺寸：`32px × 32px`
- 普通操作按钮高度：`32px`
- 主要按钮：蓝色强调色背景，白色文字
- 危险操作只在菜单或确认区域出现，不在主工具栏常驻
- 不要用文字按钮代替常见图标按钮，例如刷新、设置、更多、视图切换

常用图标建议：

- 上传：`UploadCloud`
- 下载：`Download`
- 刷新：`RefreshCcw`
- 搜索：`Search`
- 更多：`MoreHorizontal`
- 设置：`Settings2`
- 治理/安全：`ShieldCheck`
- Bucket/存储：`Database`
- 文件夹：`Folder`
- 图片：`FileImage`
- 代码：`Braces`
- 压缩包：`Archive`

## 10. 文字和密度

字体规则：

- 现阶段可以沿用项目现有字体栈。
- 不要使用负字距。
- 不要使用随 viewport 缩放的字体。
- 标题只用于页面结构，不要在工具面板里使用大标题。

字号建议：

- 页面 H1：`32px` 到 `36px`
- 工作区 H2：`20px` 到 `22px`
- 表格主文本：`13px`
- 表格 meta：`11px` 到 `12px`
- 指标数字：`17px` 到 `18px`
- 面板说明：`12px` 到 `13px`

密度规则：

- 用间距和分隔线组织信息，不用大卡片堆叠。
- 主页面不要出现嵌套卡片。
- 卡片只用于指标、右侧面板、弹窗、重复项。
- 页面 section 不做漂浮大卡片。

## 11. 响应式和最小尺寸策略

必须保证：

- `1280×820` 下完整展示侧边栏、中央表格、右侧检查器。
- `960×680` 下不出现页面横向滚动。
- `960×680` 下表格列可以更紧，但对象名称、状态和操作必须可见。
- 低于 `960px` 宽度时可以隐藏右侧检查器。
- 低于 `720px` 宽度时可以隐藏侧边栏，表格转为移动卡片式列表。

布局实现建议：

- 外层使用 `grid` 或 `flex`，所有可压缩列使用 `minmax(0, 1fr)`。
- 文本容器加 `min-width: 0`。
- 表格文件名、路径、Bucket 名称统一使用 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`。
- 工具栏按钮组允许内部横向滚动，但禁止页面整体横向滚动。

## 12. 交互状态

至少覆盖以下状态：

- 默认
- Hover
- Active / Selected
- Focus visible
- Disabled
- Loading
- Error / Warning
- Empty

重点规则：

- Focus visible 必须明显，不能被主题背景吞掉。
- 删除、覆盖、批量 CDN 刷新等风险操作必须有确认或二次提示。
- 批量选择后应出现固定批量操作区或在工具栏显示选中数量。
- 传输进度必须实时可见，不要只依赖通知。

## 13. 落地优先级

建议按以下顺序实现：

1. 主题变量：建立 Atlas 浅色/深色 token，并映射到现有 CSS 变量。
2. 布局骨架：标题栏、侧栏、主内容、右侧检查器。
3. BucketPage：先改核心对象表格和工具栏。
4. TransferPanel：迁移成右侧检查器中的队列模块。
5. Bucket 治理信息：迁移到右侧检查器。
6. AccountDialog / SettingsDrawer：统一按钮、输入框、面板密度。
7. 最后再做动效和细节 polishing。

## 14. 验收清单

每个页面提交前必须检查：

- `1280×820` 浅色 macOS
- `1280×820` 深色 macOS
- `1280×820` 浅色 Windows
- `1280×820` 深色 Windows
- `960×680` 浅色 macOS
- `960×680` 深色 macOS
- `960×680` 浅色 Windows
- `960×680` 深色 Windows

必须满足：

- 无页面级横向滚动。
- 标题栏按钮不遮挡命令搜索。
- Windows 窗口按钮区域保持独立。
- 表格主要列可读。
- 深色模式对比度足够。
- 中英文切换后按钮和标签不溢出。
- 125% 缩放下工具栏不重叠。

## 15. 禁止项

- 禁止恢复多套视觉方向并行。
- 禁止使用大面积紫色渐变、装饰光球、营销式 hero。
- 禁止把页面 section 做成漂浮大卡片。
- 禁止卡片套卡片。
- 禁止只做浅色模式。
- 禁止只按 macOS 标题栏设计。
- 禁止为了好看牺牲表格密度和批量操作效率。
- 禁止在工具界面放长篇使用说明文案。
