# Atlas Ops UI Prototype Source

本目录保存 `Atlas Ops` UI 设计原型源码快照，供前端实现时参考。

文件说明：

- `DesignShowcasePage.tsx`：Atlas Ops 原型页面结构，包含 macOS / Windows、最佳 / 最小尺寸、浅色 / 深色切换。
- `DesignShowcasePage.css`：Atlas Ops 视觉 token、布局、表格、侧边栏、右侧检查器和响应式规则。

执行规范请优先阅读：

- `../atlas-ops-ui-design-spec.md`

注意事项：

- 本目录是设计参考快照，不是生产路由入口。
- 落地时应复用项目现有组件、store、i18n 和 API 数据。
- 若后续继续迭代原型，请同步更新本目录和设计规范。
